{# ============================================================================= VitaNova — section markup for user-designed templates A near-copy of _shared/ats.html, and deliberately so. It exists for exactly one difference: keywords and tech stacks are emitted as one per keyword rather than as a single joined string. That matters because a custom design can choose how its tags look — plain, outlined pills, or bracketed mono — and none of those are reachable when the whole list arrives as one text node. Changing the shared macro instead would have altered the rendered output of all fifteen built-in designs, which are checked against reference PDFs; a design nobody asked to change must not move because a new feature needed a hook. Everything else follows ats.html's conventions to the letter, so a single-column custom design is parseable in the same way and for the same reasons: one column in source order, role and employer adjacent on one line, real

headings, and no text anywhere in decoration. ============================================================================= #} {% import '_shared/macros.html' as m %} {#- One element per keyword; the separator, if the design wants one, is drawn by CSS on .vn-tag rather than sitting in the text. -#} {% macro tags(items) %} {% set filled = items | select | list %} {% if filled %}
